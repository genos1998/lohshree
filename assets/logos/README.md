# Client logos — "The Companies We Power" conveyor

Logo images in this folder appear on the conveyor belt on the home page.
Name them with consecutive numbers:

    logo-1.png   logo-2.png   logo-3.png   ...

To add a logo, save it as the next number (`logo-4.png`) and refresh the
page — no code changes needed. `.png` `.jpg` `.jpeg` `.webp` `.svg` all work.

- Logos show in numeric order at 48px height (width auto, max 200px) —
  wide logos with a transparent background look best.
- If you delete a logo, renumber the rest so there are no big gaps: the page
  stops looking after 3 missing numbers in a row (and never past logo-60).
- If the folder has no logos at all, the belt runs empty.
